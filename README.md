# Sylheti-Bangla-English-Russian-Parallel-Corpus-for-NLP
The 1st open-source multi-lingual (Sylheti-Bangla-English-Russian) corpus for low-resource NLP. Built by a native Sylheti Linguistics undergrad at Kursk State University, Russia. Designed in .csv to train MT &amp; ASR tools. Goal: 5,000+ sentences to digitally preserve &amp; revitalize Sylheti via modern computational methods. (CC BY 4.0)
